Phase 5 — Surface film / 2D FLIP material layer

    
surface film module pending

    

      
      
      
      
      
      
      
    

    
This is the first connected adapter for the surface material layer discussed in the WaterPRO architecture. It does not pretend a full GPU FLIP buffer exists yet. Phase 6 — Above-surface MPM / splash conversion policy

    
splash conversion module pending

    

      
      
      
      
      
      
      
    

    
This page makes the existing Fable MLS-MPM/screen-fluid system into a WaterPRO conversion layer. The goal is not global fluid particles. The goal is a just-in-time policy: broad water stays heightfield/film/render; local high-energy events spawn 3D droplets/sheets/tendrils/crowns; returning particles are routed back into heightfield impulses, surface film deposits, foam, or future underwater bubble proxies.
